# CRAZY — Dark Lord RPG

Игровой проект на Godot 4: средневековая RPG о пути героя или злодея.

## Видение

- Глобальная стратегическая карта с отдельными 3D-локациями.
- Свободное управление героем от третьего лица.
- Переключение в тактическую камеру для войск и строительства.
- Развитие персонального замка, человеческие отряды, набеги, пленники и ответные нападения.
- Один мир и общие игровые правила для путей героя и злодея.

## Первый вертикальный срез (MVP)

1. Переход с глобальной карты в замок и деревни.
2. Передвижение и простая 3D-боевая сцена с противниками.
3. Отряд солдат сопровождает игрока.
4. Нападение на деревню приносит ресурсы и повышает угрозу.
5. Строительство стены в замке за ресурсы.
6. Отражение карательной экспедиции.
7. Сохранение и загрузка состояния мира.

## Управление прототипом

- **WASD** — ходьба персонажа / перемещение стратегической камеры.
- **Tab** — камера от третьего лица ↔ стратегическая.
- **ЛКМ / Space** — атака рядом стоящего противника (режим персонажа).
- **ПКМ** — отменить строительство.
- **R** — повернуть размещаемую стену.
- **Esc** — вернуться на глобальную карту.
- Строительство доступно из замка в стратегической камере.

## Скачать и запустить на Windows

**Godot устанавливать не нужно.** Открой [GitHub Releases](https://github.com/ThrandenSeverest/Crazy/releases), выбери последний прототип и скачай `Crazy.exe` в разделе Assets. Запусти `Crazy.exe` двойным щелчком.

Это ранний прототип: персонажи и здания пока изображены примитивами. Windows может предупредить о неподписанном приложении, поскольку у прототипа нет коммерческой цифровой подписи.

Каждый push в `main` автоматически запускает проверку Godot, экспортирует самостоятельный Windows x86_64 EXE с встроенным PCK, сохраняет EXE как артефакт GitHub Actions и публикует отдельный предварительный релиз.

Для разработчиков: можно открыть `project.godot` в Godot 4.4.1 и запустить F5.
