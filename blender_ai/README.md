# CRAZY: AI-generated meshes inside Blender (experimental)

**Goal:** match the user's black-gothic warlord using real human geometry, an armature and independently removable armor. NEVER replace meshes with cubes, cylinders or pixel-art tricks.

## Already executed and verified

GitHub Actions Blender Source-Geometry Experiment installs real Blender, imports a CC0 rigged human knight's native .blend and renders three actual views. Audit: 236 mesh objects, 25,478 vertices, armatures with 159 and 627 bones. This is NOT the desired character and is only a reusable anatomical/rig basis.

Source: https://opengameart.org/content/knight-rigged-mid-poly (crownjoshua, CC0).

blender_ai/crazy_ai_armor.py adds a Blender panel that imports actual 3D meshes from a LOCAL Hunyuan3D image-to-mesh service and sorts them into independently editable helmet/chest/shoulder/arm/leg/boot/cape/sword collections. The panel itself can be validated without GPU. Inference still requires the user's GPU and is NOT claimed complete.

## Directly in Blender: Hunyuan3D (real image-to-mesh, not procedural primitive script)

Official shape model and Blender addon: https://github.com/Tencent-Hunyuan/Hunyuan3D-2

In a separate Python environment, set up Hunyuan3D-2mini shape-only / low_vram_mode. Its API server can be started locally on 127.0.0.1:8080 (official docs explain model configuration). Do not mix packages with HeroTavern. An RTX 5070 12GB could be suitable for lighter shape generation, but Windows and CUDA/PyTorch Blackwell compatibility MUST be checked. Disable the high-VRAM texture generator initially.

Blender: Preferences > Add-ons > Install from Disk > blender_ai/crazy_ai_armor.py. Enable Crazy: AI Armor from Reference. Open viewport sidebar > Crazy AI. Choose a CLEAN, ISOLATED picture of one armor component, choose its equipment slot, then Generate real 3D mesh. The addon posts base64 image to the localhost /generate endpoint, verifies glTF binary magic bytes and imports its GLB without falling back to placeholder meshes. The output appears in CRAZY_AI_WARLORD/AI_<SLOT>. Shape refinement and rigging are a SEPARATE stage.

Backup engine: https://github.com/Stability-AI/stable-fast-3d (officially ~6 GB VRAM per image; Windows is experimental). It generates GLB but it is not connected to the Crazy Blender panel yet.

## AI-written modeling over a real skeleton (the more reliable armor route)

Source: https://github.com/danielgruginski/Humans (CC0), https://algumacoisaqq.itch.io/medieval-humans-orcs-goblins-rigged.

The author used Claude Code to produce actual editable Blender meshes, armor, rigging, cloth and animations from MakeHuman/MPFB human topology. Study src/hum_plate.py, src/hum_rig.py, src/hum_skeleton.py, src/hum_cloak.py for layered gothic and black-knight armor; do not copy a few primitive operations and call it complete. The scripts require their MPFB base source and can NOT necessarily run after merely cloning the GitHub repo. Their assets have not yet been integrated in Crazy.

## Quality gates before touching Godot

1. A real rigged body with proportions checked from front/side, plus an original editable Blender scene.
2. Multi-angle isolated views of helmet, chest, pauldrons, arms, legs, cape and sword. One game illustration does not reveal all back faces.
3. Independently editable realistic plate armor pieces with clear thickness, joint clearance, sculpted multi-layer silhouettes, metal wear, belts, buckles and red cloth.
4. Retopology, UV/textures, armature skin weights, shoulder/elbow/knee articulation and non-clipping pose screenshots.
5. Three-quarter, front, side and rear actual Blender renders compared to approved reference, not AI concept images.
6. Only after review export separate meshes and rig to Godot. No EXE release just because export passed.

No paid APIs and no online inference required at game runtime. Read model weight licenses before future commercial use. The requested character has NOT been generated by Hunyuan nor completed visually yet.
